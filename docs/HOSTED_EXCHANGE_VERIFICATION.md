# Hosted prototype checks

Observed October 27, 2026. These are authenticated HTTP checks against a protected Vercel Preview, not a browser study or evidence of real physical exchanges.

The exchange verifier completed **40 HTTP requests** with no failed assertions. A fictional three-reader example passed explicit shortlist loading without rank changes, generation, separate simulated approvals, three unique copy holds, idempotent approval retry, agreement download and outsider denial. Withdrawing an involved copy released the holds; repair produced a changed cycle with no inherited approval. Stale approval was rejected, and reload preserved the new held revision.

A separate real-mode room used two independent guest capabilities and Qloo-backed canonical identities. Session-bound identity confirmation, foreign-origin/actor denial, ranking persistence, independent shortlists, unanimous approval, stale-revision rejection and explicit completion confirmation passed. Inventory, willingness, decisions and the completion report were synthetic; **no physical handoff occurred**. Three provider results were live and one was reused from the private cache.

Qloo returned one saved rank in the small two-book scenario. Neither incoming recipient/book edge had a rank; both explicitly willing recipients remained eligible with unknown evidence. This checks provenance and eligibility, not recommendation quality or an improvement over another method.

An offline scan of 27 captured room views found no self-transfer, overlapping active member, duplicate active-copy allocation or duplicate hold. Disjoint-cycle approval preservation is covered by domain tests; this single-cycle hosted scenario does not establish that case independently.

Both fixtures also reloaded on the updated deployment with saved ranks, shortlists and cycle decisions intact. The check resumed after the example's one-hour hold deadline: the first assertion incorrectly expected still-active holds. A time-aware retry passed the documented expiry behavior: the overdue cycle became expired, its holds were released and its recorded decisions remained. The synthetic completed room remained unchanged. No new model or Qloo request was needed for this reload check.

The updated assistant deployment also passed two consecutive real Google/eve `read_room` turns using the shipped NDJSON text decoder. Both returned current room facts and completed; the cursor advanced from 15 to 30, preventing an older completed turn from satisfying the new request. These checks used fictional readers and real hosted SQL/inference. They do not verify browser rendering.

All **95 automated tests**, TypeScript, Next.js production build and eve production build passed. Publication audits found no ignored/forbidden paths or saved secrets in tracked files and no saved secret matches across 720 build files. The deployment upload audit excluded local instructions, trackers, skills, environment files and private evidence.
